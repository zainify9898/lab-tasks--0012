# Python OOP Beginner Projects

This repository contains three beginner-friendly Python examples about Object-Oriented Programming (OOP).

## Files

1. `student_class.py` — creates a `Student` class and displays student details.
2. `student_inheritance.py` — demonstrates inheritance with `Student` and `Graduate` classes.
3. `payment_polymorphism.py` — demonstrates polymorphism using `CashPayment` and `CardPayment`.

## Requirements

- Python 3
- No external libraries required

## How to Run

Open a terminal in this folder and run any file:

```bash
python student_class.py
python student_inheritance.py
python payment_polymorphism.py
```

## Topics Covered

- Classes and objects
- Constructors (`__init__`)
- Instance variables (`self`)
- Inheritance (`super()`)
- Method overriding
- Polymorphism
